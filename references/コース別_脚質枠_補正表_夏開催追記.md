## ⑦ 小倉 芝1200m

**主な重賞：** 北九州記念（7/5・ハンデ）、小倉2歳S、CBC賞（小倉開催年）

**形態：** 右回り・小回り。2コーナー奥からスタートし3コーナーまで約480m、**スタート直後から約3mを下り続ける**ためテンが極端に速い（前半3F32秒台常態）。直線293m・平坦。

**コース性質：** 持続型だが「テン超高速の消耗スプリント」。前有利が基本だが、ハイペース必至のため開催が進むと差しも刺さる二面性。

**要求プロファイル：**
- 主要素：テンのダッシュ力（下りで置かれない）／ 好位確保 ／ 失速率の低さ
- 加点要素：夏小倉の実績（時期固有の高速馬場）／ 牝馬・軽ハンデ ／ 関西馬
- ミスマッチ：テンに置かれる追込一辺倒（開幕〜2週目の高速前残りでは届かない）

| 適性タイプ | 係数 |
|---|---|
| テン速い先行＋失速小（夏小倉実績あれば尚可） | ×1.2 |
| 好位〜中団の持続差し | ×1.1 |
| 標準 | ×1.0 |
| テンに置かれる追込のみ | ×0.85 |

**補足（北九州記念・過去10年データ）：**
- 人気：1人気(1-3-1-5)複勝率50%だが、**2人気(0-0-1-9)複勝率10%**。勝ち馬の半数が6人気以下、単勝50倍以上でも(2-1-2)。三連複万馬券が10年で6回の**構造的荒れレース**
- 単勝オッズ帯の中心は5.0〜9.9倍(5-5-3)＝中位人気ゾーンが主役
- 枠：5枠(2-2-1)・6枠(2-2-4・複勝率40%)・8枠(2-2-2)の中外〜外優勢。**4枠(0-1-1)勝ち星ゼロ・7枠複勝率7.4%は癖として割引**（加算層で-1）
- ローテ：前走重賞1着(3-5-2-3)が最強シグナル。中7週以上の頭は(0-5-3-61)＝頭固定禁止。前走1400m以上(0-1-0-22)、前走4着以下の7歳以上(0-0-0-19)は消し級
- 属性：牝馬優勢・4歳複勝率トップ・関西馬断然。2024年から7月開催に前倒しされ前有利が強化（主要ステップは葵S・函館SS）
- **穴紐の機械フィルタ（2024バックテストで検証済み）：** 「当日4人気以下×斤量55.5kg以下×小倉芝1200勝ち（または同OP好走・京都芝1200重賞勝ち）」該当馬は2016年以降毎年3着内に好走馬を出している。該当馬は妙味スコアに関わらず**最低3着紐に確保**（2024年3着モズメイメイ16人気・三連単798,750円の紐がこれで拾えた）。なお同馬は4枠であり、**枠の癖データ（4枠・7枠不振）は加算層の-1どまりで消しには使わない**（消しに使うとこの紐を落とす）

**妙味係数（荒れ型・前残り寄り）：** 前向き脚質トリガー×1.3 / 末脚トリガー×0.7 / R・軽ハンデ・枠（5・6・8枠の引き）×1.2。7〜9人気帯(3-1-3)は妙味スコア上位なら機械的に紐確保。

**コース性質：** 持続型（小回り・短い直線）。マクリ・早仕掛けが決まりやすく、瞬発一発は不発になりやすい。

- ミスマッチ：後方からの瞬発一発

| 適性タイプ | 係数 |
|---|---|
| 先行・好位＋機動力（軽ハンデなら尚可） | ×1.2 |
| 中団からのロングスパート型 | ×1.1 |
| 標準 | ×1.0 |
| 後方一気の瞬発型 | ×0.85 |

**補足：** 開幕2週目の小倉記念は内・前有利が基本形。夏ローカルハンデ戦の共通則（軽ハンデ×上がり馬有利、人気信頼度低下、荒れ紐）を適用。枠は加算層で内+1程度、癖データは『レース別_過去傾向データ.md』⑪を正本として参照。

**妙味係数（前残り型）：** 前向き脚質トリガー×1.4 / 末脚トリガー×0.6 / R・軽ハンデ×1.2 / 枠×1.0。

## ⑨ 函館 芝1200m

**主な重賞：** 函館スプリントS（6月）、函館2歳S（7/19）

**形態：** 右回り・小回り。**洋芝100%**（野芝より時計がかかりパワー要求）。3コーナーまで約489m、緩い上りから直線262m（**JRA最短級**）・平坦。

**コース性質：** 持続型の極。直線最短＋洋芝で「前で運べてバテない」馬の独壇場。開催前半は圧倒的前・内有利、開催後半は内が荒れて差し・外が利く（開催週の把握が係数級に重要）。

**要求プロファイル：**
- 主要素：先行力（4角3番手以内目安）／ 洋芝・パワー馬場適性 ／ 失速率の低さ
- 加点要素：函館・札幌の洋芝実績 ／ 開催前半の内枠
- ミスマッチ：上がり勝負専門の差し・追込（直線262mでは届かない）

| 適性タイプ | 係数 |
|---|---|
| 先行＋洋芝実績完備 | ×1.2 |
| 好位の持続型（洋芝初でもパワー型血統） | ×1.1 |
| 標準 | ×1.0 |
| 瞬発のみの差し・追込 | ×0.85 |

**補足：** 函館2歳Sはキャリア1〜2戦で能力比較が難しく、テン速い逃げ先行を機械的に
上位へ。枠は「勝ち＝外枠・3着＝内枠」の列配置癖があるため『レース別_過去傾向データ.md』
⑫を正本として参照。血統は洋芝適性（欧州型・パワー系）を加点。

**妙味係数（前残り極）：** 前向き脚質トリガー×1.5 / 末脚トリガー×0.5 / 枠（開催前半の内）×1.2 / R・軽ハンデ×1.0。

**形態：** 右回り・小回り・洋芝。1コーナーまで約476m、直線262m・平坦。

- ミスマッチ：後方一気／ **58kg以上（函館記念は過去10年0-0-0-10＝R10）**

## ⑪ 新潟 芝1000m（直線・千直）

**主な重賞：** アイビスサマーダッシュ（8/2）

**形態：** JRA唯一の直線競走。左回り側の直線を使用、最初の200mが上り・2F目が最速。**内ラチ側の芝が傷んでおり、全馬が外ラチへ寄る**＝内枠は斜行ロス＋悪い芝。

**コース性質：** 完全な特殊コース。**枠が係数級に効く唯一のコース**として、ここだけは枠を係数層で扱う。

**要求プロファイル（＝枠と属性がプロファイルの主要素）：**
- 主要素：外枠（7〜8枠、馬番10番より外）／ テンのスピードで外ラチを確保できる
- 加点要素：**牝馬**（過去10年で優勝8頭が牝馬・2020年から5連勝）／ 前走1000〜1200m（3着内30頭中29頭）／ 韋駄天S4着以内(4-6-1-15) ／ 軽斤量
- ミスマッチ：前走1400m以上 ／ 韋駄天S5着以下(0-1-0-20) ／ 牡馬の500kg超

| 適性タイプ | 係数 |
|---|---|
| 外枠（7〜8枠）×牝馬×前走千直・スプリント好走 | ×1.2 |
| 外〜中枠のテン速いスプリンター | ×1.1 |
| 標準 | ×1.0 |
| 内枠（1〜4枠）※例外は下記 | ×0.85 |

**補足（近年の構造変化・重要）：** 2023年以降「内枠から一旦下げて外ラチへ寄せる」騎乗が定着し、1〜2枠×追込が【2-3-2-48】複勝率12.7%・複回収97%まで改善（従来は複勝率3.3%）。**内枠は一律消しにせず、下げて外に出せる差し馬なら☆妙味で拾う**。8枠は過剰人気傾向（単勝回収は伸びない）なので、8枠人気馬の頭固定より外枠人気薄の複勝圏狙いが妙味。
- 道悪はさらに外有利＋外の奇数枠と大外が強い

**妙味係数：** 枠トリガー（外枠人気薄）×1.5 / 内枠アウト差し型×1.2（上記の構造変化枠）/ 前向き脚質×1.2 / 末脚×0.8 / R×1.0。

## ⑫ 新潟 芝1600m／2000m（外回り）

**主な重賞：** 関屋記念（1600・7/26想定）、新潟2歳S（1600）、新潟記念（2000・ハンデ）

**形態：** 左回り・外回り。**直線658.7mは日本最長**、平坦。3〜4コーナーは緩く、実質「長い直線での上がり勝負」。上がり32秒台が出る。

**コース性質：** 瞬発型の極。全コース中もっとも末脚（上がり3F）の絶対値・確実性が支配的。前残りは「超スロー＋内前バイアス」の年に限られる。

**要求プロファイル：**
- 主要素：上がり最速級の末脚（32〜33秒台の絶対値実績）／ 直線で外に出せる位置取り
- 加点要素：左回り・東京での末脚実績 ／ 夏の軽い馬場適性
- ミスマッチ：末脚を欠く逃げ・先行（ハイペースなら即壊滅）／ 器用さだけの立ち回り型

| 適性タイプ | 係数 |
|---|---|
| 上がり最速常連の差し（絶対値も速い） | ×1.2 |
| 好位から長い脚を使える先行 | ×1.1 |
| 標準 | ×1.0 |
| 末脚を欠く前向き脚質 | ×0.85 |

**補足：** 評価ルール第7項の上がり3F補正は**このコースでは満額（+3）で運用**し、絶対値ボーナスも積極的に適用。新潟記念はハンデ戦で夏シリーズ総決算＝軽ハンデ×末脚型の妙味が最大化しやすい。枠は加算層で中〜外を微加点（+1）、内は詰まりリスク。

**妙味係数（差し型）：** 末脚トリガー×1.5 / 前向き脚質トリガー×0.5 / R・軽ハンデ×1.2 / 枠×1.0。

## ⑬ 福島 芝2000m

**形態：** 右回り・小回り。1角まで約505m、直線292m・平坦寄り（高低差1.9m）。スパイラルカーブでコーナーは流れる。

**コース性質：** 持続型。小回り×短い直線で前・内が基本だが、開催3週目以降は外差しへの移行が速い（開催週の実馬場確認が係数級）。

**要求プロファイル：**

- 加点要素：福島実績 ／ マクリ対応（3角から動ける） ／ 渋った馬場への対応
- ミスマッチ：瞬発一辺倒の後方待機（直線292mで届かない）

| 適性タイプ | 係数 |
|---|---|
| 先行・好位＋持続＋器用さ完備（福島実績あれば尚可） | ×1.2 |
| 好位〜中団の持続差し・マクリ型 | ×1.1 |
| 標準 | ×1.0 |

**妙味係数（前残り型）：** 前向き脚質×1.5 / 末脚×0.5 / R・軽ハンデ・内枠×1.0

## 夏開催の共通レジーム（3場横断・2026-07-03時点の検証メモ）

1. **人気の信頼度がG1と真逆。** 上半期G1では1人気複勝率100%（12/12）だったが、夏ローカルハンデG3では北九州記念1人気複勝50%・2人気10%、函館記念2026は1人気13着。**R13（1人気の紐保全）はG1限定のまま夏G3に拡張しない**ことをデータで再確認。
2. **頭も紐も荒れる。** 北九州記念は三連複万馬券6/10回、函館記念2026は三連単32万。妙味スコアトラックの重みを夏は一段上げ、☆を最低2頭確保。
3. **ハンデ×斤量が構造フィルタ。** 函館記念58kg(0-0-0-10)型の「重ハンデ消し」と「軽ハンデ×上昇馬拾い」を各レースの過去10年で必ず確認（R07と併用）。
4. **開催週の馬場把握が係数級。** 洋芝（函館）と夏の高速野芝（小倉・新潟）はいずれも開催前半＝前・内、後半＝外差しへの移行が速い。予想手順の「当日実馬場確認」を夏は前日レースまで遡って行う。

馬券は自己責任。予算は無理のない範囲で。
