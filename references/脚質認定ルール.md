# 脚質認定ルール（通過順の機械集計）v1

**位置づけ：** 脚質を主観ラベルでなく通過順の数値から機械的に判定するための固定手順。検証待ち仮説10の「機械認定側」の正本であり、**n=10 到達まで主観分類と両方式を併記する**（どちらかに一本化しない）。判定式の改訂は較正レビューでのみ行う。

**実行タイミング：** `#準備` セッション（特別登録＝月〜火以降、枠順は不要）。予想セッション内で初めて脚質を決めるのは禁止。工程4のペーススコアは本ファイルの認定値を入力とする。

**起点となった事故：** 七夕賞2026で16頭中4頭を誤分類、小倉記念2026で✕⑦トータルクラリティが脚質未取得のまま逃げ（1-1-1-1）、関屋記念2026で☆⑩クランフォードを差しと分類したが逃げ切り2着。**3レース連続**で単騎判定・ペーススコア・隊列・妙味トリガーに連鎖した。

## 1. 入力データ

出走想定馬ごとに**直近5走**（重賞勝ち馬・◎○候補は工程2に合わせて可能な限り全走）について、以下を取得する。

| 項目 | 内容 | 備考 |
|---|---|---|
| 通過順 | 各コーナーの順位（例 `1-1-1-1`） | 最初と最後（4角）の2点を必ず使う |
| 頭数 | その走の出走頭数 | 相対化に必須 |
| 距離・コース | 芝/ダート・距離・競馬場 | 除外判定用／**§6で必ず出力する** |
| 馬場 | 良/稍重/重/不良 | 注記用／**§6で必ず出力する** |
| 着順 | その走の着順 | **§6で必ず出力する**（`5走距離帯=` タグの構成要素） |
| 格 | G1/G2/G3/L/OP/3勝/2勝/1勝/未勝利/新馬/地方/海外 | **§6で必ず出力する**（R25の発火判定に使う） |

> **2026-08-17 追記（中京記念2026の `#設計`）：** 距離・馬場は v1 の時点で取得対象だったが、
> §6の出力形式に欄がなかったため**4角相対位置へ変換する過程で捨てられ、予想工程に届いていなかった**。
> 実成果物4ファイル（アイビスSD／クイーンS／札幌記念／中京記念）はいずれも同じ10列で距離・馬場を持たない。
> 中京記念2026の2着⑤ミニトランザット（良[4-0-2-2]／稍重[0-0-0-3]・前走は稍重での6着）を
> 良馬場のレースで無印に置いた失点がこの経路で説明できる。**取得は規定どおり行われていた。欠けていたのは保持と受け渡し。**

出典は**JRA公式を第一**とし、`python3 tools/jra_result.py --date <YYYY-MM-DD> --course <場> --race <R>` で通過順・コーナー通過順位を取得する。JRA公式に無い走（地方・海外）や収録範囲外の過去開催は Yahoo競馬のデンマ／レース結果ページで補う。**取得できなかった走は「未取得」と明示し、推測で埋めない。**

> 2026-08-02 訂正：本行はもと「JRA公式はBot検出でブロックされる」としていたが、再検証で `www.jra.go.jp` の robots.txt は全面許可（`Disallow:` 空）、正直なUAでGET 200 を確認した。ブロックではなく、結果画面が `/JRADB/accessS.html` の CNAME 遷移であることが到達できなかった原因。`jra_result.py` の追加で解消済み。

## 2. 相対位置の計算

各走について、コーナー通過順位を頭数で正規化する。

```
相対位置 r = (通過順位 − 1) ÷ (頭数 − 1)
```

`r = 0.0` が先頭、`1.0` が最後方。18頭立ての4角5番手なら `r = 4 ÷ 17 = 0.24`。

- **r_med** ＝ 直近5走の**4角相対位置の中央値**（平均でなく中央値。1回の出遅れ・大敗で歪まないため）
- **単独ハナ回数** ＝ 最初のコーナー（記録された最初の通過順）が**1位**だった走の数
- **IQR** ＝ 4角相対位置の四分位範囲（ばらつきの指標）

新潟芝1000m直線などコーナーのない条件は、記録された唯一の通過順を4角相当として扱い、単独ハナ判定にも同じ値を使う。

## 3. 判定式

上から順に評価し、最初に該当した区分を採る。

| 区分 | 条件 |
|---|---|
| **逃げ** | 単独ハナ回数 ≧ 2（5走中）**または** 直近3走に単独ハナ1回以上。かつ `r_med ≦ 0.15` |
| **先行** | `r_med ≦ 0.35` |
| **差し** | `0.35 < r_med ≦ 0.70` |
| **追込** | `r_med > 0.70` |

**自在フラグ：** 上記の区分に加え、`IQR ≧ 0.30` なら `自在` を付す。自在馬は展開2パターンの**両方に配置**し、単騎逃げ判定の分母には入れるが確定要素として扱わない。

**ハナ争いの強度：** 逃げ認定馬が2頭以上いる場合、各馬の「単独ハナ成功率＝単独ハナ回数÷5」を併記する。成功率が最も高い1頭を主導権本線とし、残りは競り込み側として隊列シミュレーションに渡す。

## 4. 除外・補正

- **原則として走を除外しない。** 除外基準を増やすと少走馬が量産され、未取得と同じ事故を招く
- 次の走は**注記のみ**付けて計算には含める：今回と距離差 ±400m 以上／馬場が不良／出遅れの明記があるもの
- ダート→芝、芝→ダートの臨戦は注記を付す（ダート戦をフレームワーク対象とするかは未判断）
- 前走から6か月以上の休養明けは、休養前の走を含めたうえで注記する

## 5. データ不足時の扱い（最重要）

**3走未満しか取得できない馬は `脚質=未確定` とする。** このとき以下を必ず守る。

- **未確定馬を「逃げない馬」として扱わない。** 小倉記念2026の事故（脚質未取得の✕評価馬が逃げてペーススコアの前提を壊した）はこの誤りが原因
- 未確定馬はペーススコアの逃げ・先行カウントに算入しない代わりに、**「未確定馬が逃げた場合」のシナリオを展開2パターンのどちらかに必ず含める**
- 2歳戦・新馬勝ち上がり直後は未確定が常態なので、血統（父の先行率）と調教過程の情報を注記に添える。ただし**注記は脚質認定の代用にしない**

## 6. 出力形式

`#準備` セッションで全出走想定馬について1頭1行を出力する。

```
#7 トータルクラリティ｜4角r [0.06, 0.12, 0.06, 0.18, 0.06] r_med=0.06 IQR=0.06
　　単独ハナ 3/5 → 機械=逃げ ／ 主観=先行 ／ ★不一致
　　5走距離帯=1200:良:1着:OP;1200:稍重:5着:G3;1400:良:3着:L;1200:良:2着:3勝;1200:重:9着:G3
```

**3行目は `predictions.csv` の `base_breakdown` へそのまま貼る形式で書く**（記録原則12・2026-08-17〜）。
書式は `距離:馬場:着順:格` を `;` 区切りで近走順。取れない項は `不明` と書き、要素数は常に4つに揃える。
レース単位の一覧表を作る場合も**距離・馬場・着順・格の列を落とさない**。
これは「準備で取ったものが予想工程へ届く」唯一の経路であり、`validate.py` A-3/A-3b が欠落と書式崩れをWARNで検出する。

- `機械` と `主観` が食い違う馬には `★不一致` を付け、**不一致頭数をレース単位で集計して records する**（仮説10の判定材料）
- 未確定馬は `機械=未確定（取得2走）` と書き、走数を明示する

## 7. 下流への接続

| 接続先 | 使い方 |
|---|---|
| 工程4 ペーススコア | **機械認定側の値**で「逃げ×2＋先行×1」を計算する。主観側で計算した値との差はnotesに残す |
| 単騎逃げ判定（R04） | 逃げ認定が1頭のみ、かつその馬の単独ハナ成功率 ≧ 0.4 のときだけ「単騎」と宣言する |
| 工程5 隊列シミュレーション | 自在フラグ・ハナ争い強度をそのまま入力に使う |
| 妙味スコアの脚質トリガー | 機械認定と一致する場合のみ加点する。主観のみを根拠にした脚質加点は行わない（関屋記念☆⑭の妙味の一部が脚質仮定に依存していた事例） |
| **工程2 過去走調査** | §6の `5走距離帯=` 行を**全頭ぶん**渡す。工程2の馬場実績ゲートは◎○限定なので、**無印・消しになる馬の距離／馬場適性はこの経路でしか工程6に届かない**（2026-08-17追加） |
| **工程6 各馬評価** | `base_breakdown` に §6の `5走距離帯=` 行をそのまま転記する（記録原則12）。R38の未経験判定・R25の発火判定・仮説20-d・仮説23の集計入力を兼ねる（2026-08-17追加） |

## 8. 保存先

- **認定結果**：`horse/` の個別馬メモに `脚質認定（YYYY-MM-DD時点）: 機械=逃げ / r_med=0.06 / 単独ハナ3/5` の形で残す。再出走時は直近走を足すだけで済む
- **レース単位の不一致集計**：`log/races.csv` の notes に `脚質不一致=2/14` を記録する（仮説10のn=10判定用）
- 判定式そのものの改訂は本ファイル。個別馬の型は `horse/`、レースの傾向は `レース別_過去傾向データ.md` に分ける

## 9. 仮説10との関係

本ファイルは仮説10の「機械集計方式」を固定するもので、**主観方式の廃止を意味しない**。n=10 到達時の較正レビューで、レース単位の不一致率と、不一致馬の実際の走り方（どちらの方式が当たっていたか）を照合し、一本化の可否を判定する。それまでは併記を続け、片方の値だけを根拠に印・買い目を動かさない（R19）。
