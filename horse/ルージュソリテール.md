# ルージュソリテール

- **性齢／所属：** 牝4／栗東・藤原英昭厩舎（父ロードカナロア、母父ディープインパクト）
- **得意条件（コース・距離・馬場）：** 芝1600〜1800m良。阪神牝馬S(G2)3着、マレーシアC勝ち
- **脚質・位置取り：** **先行**。ただし逃げ馬の直後を取りに行く極端な前寄り
  - `脚質認定（2026-07-31時点）: 機械=先行 / r_med=0.111 / 単独ハナ0-5 / IQR=0.10 / 自在なし`
  - `※r_medは逃げ級だが5走すべてハナを主張していない。「2番手を確保する型」として扱う`
- **斤量・馬体重の適性レンジ：** 55〜56kg。428〜450kgの小柄
- **気性・癖：** 前が壁になると崩れる（府中牝馬S 7-2-2で12着）。自ら動いて位置を上げるが持続しない
- **鞍上相性：** 西塚洸二で3戦（1着・3着・12着）
- **直近の注目ポイント：** **逃げ馬の隣・直後を必ず取る**ため、隊列シミュレーションでは逃げ馬の圧迫要因として配置する
- **次走狙い：** 単騎逃げ馬がいる組み合わせでは、その馬を潰す側に回る。ハナ争いの分母には入れない
