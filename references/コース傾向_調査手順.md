# コース傾向 調査手順（新規コース収録ワークフロー）

補正表エントリを作るための固定工程 C0〜C6 ／ v1

**位置づけ：** 予想の「工程0〜12」・振り返りの「V0〜V7」と対になる、**コース収録の固定工程**。指示の自動トリガー「開催替わり」（未整備コース検知→追記提案）が発動したとき、および「◯◯コースの傾向を調べて」と依頼されたときは、必ずこの手順で調査し、品質ゲート（C6）全✓のエントリだけを補正表へ追記する。感想ベース・記憶ベースのコース評は収録しない。

**成果物：** 『コース別_脚質枠_補正表.md』（または夏開催追記版）への追記ブロック1件。レース固有データが分離対象になる場合は『レース別_過去傾向データ.md』への追記行もセットで出力する。

**起点：** 「コース傾向を調べて」「◯◯（未収録コース）の予想」「補正表に追加」等で発動。セッション冒頭の同期チェック（最新main取得→validate）は通常どおり先に行う。

---

## C0. 対象宣言（調査開始時・必須）

工程1に入る前に以下を1ブロックで出力する。宣言なしの調査着手は禁止。

- **対象コース：** 競馬場／芝・ダート／距離／回り（内・外・直線）
- **対象重賞：** このコースで施行される重賞と時期（ハンデ・別定の別も）
- **既収録判定：** 補正表2ファイルの `## ` 見出しを機械確認（grep相当）した結果。**既収録なら新規調査ではなく既存エントリの改訂扱い**とし、改訂根拠（n件のログ実測 or 形態変更）を先に宣言する
- **追記先とエントリ番号：** 本体（主要重賞コース）か夏開催追記版か。既存の連番（現在①〜⑬）の次番号
- **ルーティング宣言：** レース固有データの置き場所を先に決める（下記「ルーティング規則」参照）

### ルーティング規則（コース普遍 vs レース固有）

正本は必ず一方のみに置き、他方は参照1行にとどめる（二重管理の禁止）。

| データの種類 | 正本 |
|---|---|
| 形態由来・全レース共通の傾向（コーナー距離、坂、テン速度、枠バイアスの構造要因） | 補正表エントリ本体 |
| そのコースの重賞が**1つだけ**の場合の当該重賞10年データ | 補正表エントリの「補足」に埋め込み可（北九州記念方式） |
| 同一コースで重賞が**複数**施行される、またはデータが長大な場合 | 『レース別_過去傾向データ.md』へ分離し、補正表側は要約1〜3行＋参照 |

## C1. 形態調査（数値はJRA公式が正本）

1. JRA公式のコース紹介・コース図を検索し、以下の数値を取得する：**スタート〜初角距離／直線長／高低差・坂の位置と勾配／コーナー形状（スパイラルの有無・小回り度）／スタート地点の特性（下り・ポケット等）**
2. Claude.ai では web検索、Claude Code では `polite_fetch.py` 優先（403等は回避せずJRA公式へ切替）。**取得失敗した数値は推測で埋めず「取得失敗」と明記**する
3. 形態から予想される力学を1〜2行で仮説化する（例：下りスタート→テン超高速→消耗戦）。**この時点では仮説であり、C2の統計と突き合わせて初めて採用**する

## C2. 過去10年統計（4指標＋荒れ度素材・必須）

JRA公式（またはそれに準ずる一次集計）の過去10年データを検索し、以下を**数値で**収録する。単一年・単一レースの印象での代用は禁止（単一レースデータでアンカーを上書きしない原則）。

1. **人気別：** 1〜3人気の複勝率、勝ち馬の人気分布、特異な人気帯（例：2人気だけ極端に不振）
2. **枠別：** 勝率・複勝率の偏り。**構造要因（形態由来）か癖（統計上の偏りのみ）かを区別**する
3. **脚質・通過順別：** 4角位置別成績、逃げ残り率、上がり最速馬の成績
4. **ローテ・属性：** 前走クラス・間隔・距離変更、性齢・所属・斤量帯の偏り
5. **荒れ度素材：** 三連複万馬券の回数、単勝50倍以上の好走数（荒れ度スコア算出と妙味係数設定の入力になる）

### 消しデータ／癖データの区分（必須）

見つけた負のデータは必ず次のどちらかに区分してから収録する。区分なしの「不利」表記は禁止。

- **消し級：** サンプル十分・構造要因あり・例外がほぼない（例：函館記念58kg以上0-0-0-10）→ 構造フィルタとして使用可
- **加算層どまり（±1）：** 統計上の偏りのみで構造説明が弱い、または例外好走がある（例：北九州記念の4枠・7枠不振。2024年3着モズメイメイは4枠）→ **消しに使うと穴紐を落とす**ため加算層−1まで

## C3. コース性質判定

C1の形態仮説とC2の統計を突き合わせ、**持続型／瞬発型／二面性**のいずれかに判定する。判定基準：

- 直線長（目安：350m未満=持続寄り、450m超=瞬発寄り）＋坂の有無・位置
- 4角位置別成績（前有利の実測が形態仮説と一致するか）
- テンの速さ・ペースの出やすさ（二面性の主因：前有利形態×ハイペース必至、等）

既存①〜⑬から**最も近い類似コースを1つ挙げ、差分を1行で**述べる（例：小倉2000に近いが急坂ありの分パワー要求が加わる）。類似コースの係数設計を出発点にすることで初期値のブレを抑える。

## C4. 要求プロファイル起草

既存体系と同一の枠組みで書く。独自の段数・係数を発明しない。

- **主要素：** 2〜3個（勝ち負けに必須の適性）
- **加点要素：** 1〜3個（時期固有実績・斤量・所属などを含めてよい）
- **ミスマッチ：** 明確に割り引く型を1つ
- **係数表：** ×1.2／×1.1／×1.0／×0.85 の4段固定

## C5. 妙味係数設定

C2-5の荒れ度素材と穴馬の共通パターンから、3トリガー（**前向き脚質／末脚／R・軽ハンデ・枠の引き**）の重みを設定する。過去10年の3着内人気薄（6人気以下）の脚質・枠を数え、多数派トリガーを×1.2〜1.5、少数派を×0.5〜0.7とする。機械フィルタ（例：北九州記念の穴紐フィルタ）を立てる場合は、**バックテスト（過去年での該当馬の3着内実績）を1行添える**。

## C6. 品質ゲート（全✓で収録可）＋出力

| # | ゲート項目 |
|---|---|
| 1 | 形態数値がJRA公式ベースで、出典の取得可否（取得失敗含む）が明示されている |
| 2 | 過去10年統計が4指標（人気・枠・脚質・ローテ）以上、数値で収録されている |
| 3 | 負のデータすべてに「消し級／加算層どまり」の区分が付いている |
| 4 | 係数が4段固定で既存体系と同一（独自段数・独自係数レンジなし） |
| 5 | 妙味係数が3トリガーすべてに設定され、根拠（穴馬パターンの数え上げ）がある |
| 6 | 「数値は初期値、log/で結果を記録しながら調整」の明記があり、単一レースでの書き換え禁止を確認した |
| 7 | エントリ番号・見出し体裁が既存と整合し、ルーティング宣言（C0）どおりに正本が1箇所である |

**出力順序：** C0宣言の再掲（確定版）→ 補正表への追記ブロック（既存体裁のMarkdown、コードブロックで提示）→ レース別ファイルへの追記行（該当時）→ 品質ゲート表（全✓確認）。

**収録後の同期：** ファイル追加を伴わない補正表への追記のみなら README/SKILL 更新は不要。新ファイルを作る変更をした場合のみ三点同期の対象。

## 更新サイクル（収録後の育て方）

- 収録エントリの数値はすべて**初期値**。実レースの結果は振り返り（V0〜V7）の教訓ルーティングに従い、コース傾向系の教訓を当該エントリの「補足」へ追記する
- **係数・妙味係数の変更はn=10較正レビューのタイミングで検討**する。単一レースの結果（1回の前残り・1回の外差し）でプロファイルや係数を書き換えない
- 開催が進むにつれた馬場移行（夏ローカルの前有利→外差し）はエントリ側に書かず、夏開催追記版の「共通レジーム」節で横断管理する
