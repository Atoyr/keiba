# 荒れ度スコアと買い目配分表 v2

**本ファイルが荒れ度の正本。** 定義（スコア算出）・帯域判定・買い目への反映はすべてここで管理する。『競馬予想_評価ルール.md』旧第11項の定性ランク（高/中/低）方式は本ファイルへ統合し廃止した。『レース別_過去傾向データ.md』の荒れ度メモは参考情報であり、判定は毎回このスコア式で行う。

荒れ度を工程内で**必ず数値として算出**し、買い目構築に機械的に反映する。荒れ度はベース点・印の序列には一切触れない（触れてよいのは頭固定の判断・紐の頭数・☆の数・妙味閾値・予算配分・券種だけ）。

## 0. 絶対原則（旧第11項から継承）

**荒れ度はベース点（地力）に絶対に触れさせない。** 「荒れるレースだから人気薄を一律加点」は誤り。荒れ度統計は「平均して荒れる」を示すだけで、「どの人気薄が来るか」は何も教えない。人気薄全体を持ち上げると、来ない多数を一緒に上げて評価が薄まり、無駄打ちが増えて回収率はむしろ悪化する（2024年ラジオNIKKEI賞バックテストで実証：前残り妙味の一律拾いで来たのは1頭、他は8〜10着）。

穴は「全体を持ち上げて」ではなく「妙味トラック（評価ルール第10項）で1〜2頭に絞って」拾う。荒れ度はその絞り込みを後押しする補助情報に徹する。また荒帯域でも1番人気は「消す」のではなく「頭から外す（紐には残す）」。極端な人気軽視はしない。

### 中帯域から三連単Fを外した理由（2026-08-03・暫定改訂／ロードマップP2-3）

**根拠は「n=10で0的中だったこと」ではない。** 予算3,000円・単価100円で組める三連単Fは12〜15点＝1,200〜1,500円で、
第5項の式による概算的中率は約1%。**想定的中率が1%なら10レース連続不的中はごく普通の結果**であり、
0/10は -EV の証拠としてほとんど情報を持たない（0/10から言える的中率の95%上限は26%）。

**実際の根拠は損益分岐配当が中帯域の配当レンジに構造的に届かないこと。**

| | 中帯域の実測 |
|---|---|
| 三連単F 14点の損益分岐配当（関屋記念2026） | **132,171円**（的中率1.06%） |
| 同レースの実際の三連単配当 | 34,830円 |
| クイーンS2026 の三連単配当 | 22,210円 |

損益分岐が実配当の**4〜6倍**で、当てても回収できない構成になっている（第5項の `EV警告` 該当）。
第5項は「数値を残すだけ・採否の閾値化は n=10 レビューの議題」としていたが、**n=10 に到達したので
ここで採否に反映する**。荒帯域は三連単配当が20〜80万円規模になり損益分岐を超えうるため**残す**。

**留保：** 中帯域でも高配当は出る（アイビスSD2026＝三連単462,350円）。ただしその決着は上位人気を
頭に置く我々の三連単Fには入っていない。**「高配当が出るときは我々の買い目に含まれない」**という
非対称がこの改訂の本質で、n=10ではこれを確定的には示せていない。
**レビュートリガー：n=20 で荒帯域の三連単F成績を再判定し、そこでも損益分岐を超えられないなら全帯域から外す。**
実購入の通算：三連単系 13,600円投資・0回収（三連単8,400円＋三連単F5,200円）／同期間の三連複 189%。

- 「妙味☆採用閾値」は評価ルール第10-4項の☆採用ライン。荒帯域に限り5→4へ1段下げ、☆枠を1頭広げる（人気薄全体の底上げではなく、妙味トラックで既に絞った中の採用幅を1つ広げるだけ）
- 帯域は印・序列に影響させない。R12（三連単の頭◎○両置き）は全帯域で維持
- **荒帯域では、コース別補正表の「穴紐の機械フィルタ」該当馬（例：小倉1200の当日4人気以下×55.5kg以下×小倉/京都1200実績）を妙味スコアに関わらず紐に確保**する
- 荒帯域で紐を広げる際の優先順位：機械フィルタ該当 → R≧4.0 → 妙味スコア上位 → 7〜9人気帯。人気順では広げない
- G1は原則「堅〜中」に収まり、R13（1人気の紐保全）が優先される
- 帯域は「レースの型」の初期値であり、当年メンバーで上下しうる（抜けた1強がいれば荒帯域でも堅くなる）。当年構成で微調整してよいが、調整理由を宣言行に添える

## 4. 点数の検算式（R16・買い目確定前に必ず実施）

買い目ごとに点数を式または列挙で明示し、「点数×単価＝金額」「合計＝予算内」を照合してから確定する。

**単純な型（式で一発）：**

| 券種・型 | 点数 |
|---|---|
| 三連複 軸1頭流し・相手n頭 | n×(n-1)÷2 |
| 三連複 軸2頭流し・相手n頭 | n |
| 三連複 BOX n頭 | n×(n-1)×(n-2)÷6 |
| 馬連・ワイド BOX n頭 | n×(n-1)÷2 |
| 三連単 BOX n頭 | n×(n-1)×(n-2) |
| 馬単 BOX n頭 | n×(n-1) |

**フォーメーション（集合が重複する場合は式でなく「頭ごとの展開」で数える）：**

三連単F（1着A・2着B・3着C）は A×B×C の掛け算では**数えられない**（同じ馬の重複分を除外するため）。頭の馬を1頭ずつ固定して展開する：

```
点数 = Σ 頭x∈A ごとに： Σ 2着y∈B（y≠x）ごとに： 3着候補 = |C から x,y を除いた頭数|
```

検算例（頭◎○両置きの典型）：1着{7,12}・2着{7,12,4}・3着{4,9,11}
- 頭7 ： 2着12→3着{4,9,11}=3点 ／ 2着4→3着{9,11}=2点 → 計5点
- 頭12： 2着7→3着{4,9,11}=3点 ／ 2着4→3着{9,11}=2点 → 計5点
- **合計10点**（2×3×3などの掛け算に頼ると12点等に誤る）

三連複Fも同様に、組（順不同）を列挙して重複組を1つに数える。**10点以下の買い目は全列挙を書き出すのが最も確実**。宣言行の直後に「検算：式または列挙 → 点数 → ×単価 → 金額」を1行添える。

## 5. 期待値の可視化（買い目確定前・数値出力のみ）

点数の検算（第4項）に続けて、券種ごとに1行を出力する。**判断は変えない。数値を残すだけ**（採否の閾値化は n=10 レビューの議題）。

```
<券種> N点 ／ 概算的中率 X.XX% ／ 損益分岐配当 Y円 ／ 過去10年の同券種配当レンジ Z
```

**的中率の算出（Harville近似）**
1. 全頭の市場確率 `p_i = (1/単勝オッズ_i)` を求め、総和が1になるよう正規化する（控除率はここで吸収される）
2. 三連単 `i→j→k` の確率 ＝ `p_i × p_j/(1-p_i) × p_k/(1-p_i-p_j)`
3. 三連複 `{i,j,k}` ＝ 上記6順列の和。ワイド `{i,j}` ＝ 両馬が3着内に入る確率の和
4. 券種の的中率 ＝ 買い目に含まれる全通りの確率の和

**損益分岐配当** ＝ `その券種の投資額 ÷ 的中率 ÷ (単価÷100)`

**運用ルール**
- 損益分岐配当が「過去10年の同レース・同券種の最高配当」を超える構成は、`races.csv` の notes に `EV警告=<券種>` を残す。買い方は変えず、n=10 レビューでの検討対象として印を付けるだけ
  - **※ n=10 到達（2026-08-02）を受けて、中帯域の三連単Fは第2項の帯域表から外した（2026-08-03）。**
    `EV警告` の仕組み自体は継続する（他の券種・帯域で同じ構造を検出するため）
- オッズ未取得の段階では算出せず「オッズ未確定につき未算出」と明記する。推測値で埋めない
- 実測例（関屋記念2026）：三連複 軸1頭流し10点＝的中率6.07%・損益分岐16,464円（実配当7,490円）／三連単F14点＝的中率1.06%・損益分岐132,171円（実配当34,830円）。後者は `EV警告` 該当
